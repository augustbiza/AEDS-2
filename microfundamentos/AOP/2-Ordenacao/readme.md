# Seleção
## Seleção Menor
Define o primeiro elemento como **menor**.  
Busca o menor elemento do array a partir do 2 elemento.  
Troca o menor elemento com o da primeira prosição.  
Define o segundo elemento como **menor**.  
Busca o menor elemento do array a partir do 3 elemento.  
Troca o menor elemento com o da segunda prosição.  
## Seleção Maior
Define o último elemento como **maior**.  
Busca o maior elemento do array a partir do **penúltimo** elemento.  
Troca o maior elemento com o da ultima prosição.  
Define o penúltimo elemento como **maior**.  
Busca o maior elemento do array a partir do **antepenúltimo**.  
Troca o maior elemento com o da penúltima posição.
